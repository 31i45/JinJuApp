# JinJuApp

在屏幕左下角（任务栏带内）常驻显示一行金句的 Windows 桌面小工具：每 3 分钟换一句，长句自动横向滚动，不打扰、不抢焦点、不写注册表（除非你主动开启自启动）。**全屏看视频、玩游戏或开启勿扰模式时自动隐藏**，退出后自动恢复。

v2.0.0 起为纯 Rust + Win32 原生实现（原为 Python/PyQt，见文末「为什么重写」）。

## 使用

1. 从 [Releases](https://github.com/31i45/JinJuApp/releases) 下载 `JinJuApp.exe`，放入任意可写目录；
2. 双击运行：金句条出现在底部任务栏的空闲区域，托盘出现图标；
3. **换内容**：托盘右键 →「编辑金句」，或直接编辑 exe 旁的 `quotes.txt`；
4. **开机自启动**：托盘右键 →「开机自启动」（默认关闭，由你决定）；
5. **退出**：托盘右键 →「退出」。

无需安装，无运行时依赖，约 250 KB。

> **任务栏位置**：本程序**仅针对底部任务栏**做了完整的锚点探测与动态跟随（居中/靠左对齐模式均支持，运行时切换自动适应）。顶部、左侧、右侧停靠的任务栏**不建议使用**——此时金句条不会避让任务栏上的图标与控件，可能出现重叠或遮挡。

## 全屏与勿扰

- **全屏应用**（游戏、视频播放器、浏览器 F11）→ 金句条自动隐藏，退出全屏后自动恢复原位；
- **勿扰模式 / 专注助手（Focus Assist）与演示模式** → 隐藏（系统级「请勿打扰」意图，所有显示器一律隐藏）；
- 多显示器：某块屏幕全屏时只隐藏该屏幕上的金句条，不做跨屏误伤；
- 检测每 500 ms 一次，进入/退出全屏后约半秒内响应；隐藏期间完全不绘制，也不抢焦点。

## 金句数据

`quotes.txt` 位于 exe 同目录，首次运行时自动导出内置的 **209 条精选金句**（六大来源：古代经典、人民日报精选、网络金句、文学名著、高考学习、考公职场），**一行一句纯文本**：

```
千里之行，始于足下。
愿你成为自己的太阳，无需借谁的光。
路虽远，行则将至；事虽难，做则必成。
```

- 内置语料统一按 **6–45 字** 精选（主力落在 12–30 字），无重复、无超长拖沓句；
- 以 `#` 开头的行是注释（分类标题等），加载时自动跳过；
- 改文件即改内容，**不需要重新下载程序**——英语单词、待办、座右铭，放什么都行；
- 文件损坏或语法错误时，弹窗给出具体行号与原因，本次回退内置金句运行，不会静默失败；
- 加载优先级：`quotes.txt` → `quotes.json`（遗留兼容）→ 内置语料；
- 旧版 `quotes.json` 首次遇到时自动迁移为 `quotes.txt`，原文件保留。

## 构建

```bash
cargo build --release        # 产物 target/release/JinJuApp.exe，约 230 KB
cargo test                   # 84 个单元测试
cargo clippy --all-targets -- -D warnings   # 零警告
powershell -File e2e.ps1     # 18 项端到端冒烟检查
```

要求：Rust 1.85+（edition 2024）与 Windows SDK（资源编译器，用于嵌入图标）。二进制只由 GitHub Actions 构建发布（tag 触发，附 SHA-256 校验和），仓库不跟踪任何可执行文件。

## 工程说明

- **模块**：`quotes`（数据加载/校验/兜底 + 洗牌袋 + xorshift）、`layout`（跑马灯状态机）、`geometry`（任务栏四边几何与窗口放置）、`render`（灰度掩码 → 预乘 ARGB 纯函数 + GDI 宿主）、`startup`（opt-in 注册表自启动）、`tray`（托盘与菜单）、`win32`（手写 FFI——本程序对系统的全部调用集中在一个文件）；
- **FFI 决策**：有意不引入 windows-rs / winapi 等绑定库。本程序用到的 Win32 调用总量很小（六个系统 DLL），手写声明换来零第三方运行时依赖、单个文件即可整体审计、编译极快；代价（少量声明需自行维护、正确性靠人工核对文档）由单元测试与 E2E 覆盖；
- **渲染**：per-pixel-alpha 分层窗口，GDI 白字黑底获得逐像素覆盖度，再转为预乘 ARGB 上屏；灰度抗锯齿（ClearType 在透明表面上会产生彩边）；
- **跑马灯**：窗口固定不动，只滚动文字，**文字长度不限**——静止 2 秒展示句首，向左匀速滑动到**句尾抵达显示区右缘即停**，停留 0.6 秒后原地淡出（250ms），于完全不可见处瞬移回句首再淡入（250ms），循环往复——复位跳变发生在 alpha=0 处，肉眼只见平滑的淡出复位，无擦回跳变；换句为 400ms 交叉淡化：旧句原地淡出、新句在静止位淡入。45 逻辑 px/s，随 DPI 缩放（对照原 Python 版语义，并消除了其擦回越冲+瞬移瑕疵）；
- **适配**：底部任务栏做锚点探测——枚举 Shell_TrayWnd 子窗口的 `ReBarWindow32`/`MSTaskSwWClass`（图标集群）与 `TrayNotifyWnd`（系统托盘），判定 Win11 居中（图标集群与任务栏左边缘有间隙 → 条在最左端）还是 Win10 靠左（图标集群紧贴左边缘 → 条在图标与托盘之间）。宽度随集群/托盘动态收缩，无重叠。顶部/侧边停靠任务栏显示在其桌面侧，不做锚点感知；深色/浅色主题通过读取注册表 `AppsUseLightTheme` 自动跟随（深色 → 白字，浅色 → 深灰字）；DPI 变化、explorer 重启（托盘自动恢复）、单实例互斥、`Win+D` 后在下一次换句时温和恢复（不做每秒对抗式自愈）；每 500ms 重申 z 序 + 重新探测任务栏锚点——explorer 把任务栏抬到金句条之上时约半秒内自动恢复，切换任务栏对齐模式同样半秒内跟随。同一 500ms 节拍里检测全屏：`ShQueryUserNotificationState` 拿勿扰/演示等全局状态（`QUNS_QUIET_TIME`、`QUNS_PRESENTATION_MODE`），再拿前台窗口矩形与金句条所在显示器矩形比对（2px 容差）判定全屏应用；命中即 `SW_HIDE`，恢复用 `SW_SHOWNOACTIVATE` 重新锚定，换句定时器在全屏期间不会把条强行拉回来。
- **测试边界**：全部决策逻辑为纯函数并以单元测试覆盖；窗口/GDI/注册表等系统交互由 `e2e.ps1` 做程序化端到端验证，不为 FFI 边界做 mock。

## 为什么从 Python 重写

原 Python/PyInstaller 版本（v1.0，已从主干移除，历史保留在 git）存在结构性问题：

| 问题 | 原版 | v2.0 |
|---|---|---|
| 体积 | 35.2 MB | 248.5 KB |
| 杀软误报 | PyInstaller bootloader + UPX 壳命中 Defender 机器学习「dropper」画像（[#1](https://github.com/31i45/JinJuApp/issues/1) 报 `Wacatac.C!ml`） | 纯静态原生代码，无 bootloader、无壳、无打包器 |
| 内容更新 | 数据焊死在 exe 内，改一个字要重新发版 | 外置 `quotes.txt`（一行一句纯文本），用户即改即生效 |
| 自启动 | 首次运行静默写注册表，无退出途径 | 默认关闭，托盘一键开关，可退出 |
| 错误处理 | 数据错误静默吞掉，只显示兜底句 | 错误弹窗直达用户，含原因与修复路径 |
| 可测性 | 纯逻辑焊死在 QWidget 中，0 测试 | 84 单元测试 + 18 项 E2E，全绿 |
